Переводы интерфейса
==================

- `app_ru.arb` — русские надписи.
- `app_en.arb` — английские надписи с теми же ключами.
- `app_localizations*.dart` создаёт Flutter. Вручную их редактировать не нужно.

После добавления новой надписи:

1. Добавь одинаковый ключ в оба ARB-файла, например `"cancel": "Отмена"` и `"cancel": "Cancel"`.
2. Выполни `flutter gen-l10n`.
3. В методе build получи `final l10n = AppLocalizations.of(context);` и используй `Text(l10n.cancel)`.

При первой настройке выполни `flutter pub get`, затем `flutter gen-l10n`.

Как переключается язык:

`RU / EN → AppSettingsController.setLanguage → notifyListeners → locale в CupertinoApp → обновление надписей`.

Язык пока хранится в памяти: после перезапуска снова выбран русский.
Имена, названия тренировок и другие данные из SQLite не переводятся автоматически.
Готовые шаблоны тренировок пока тоже остаются данными на русском языке.
Формат даты в форме остаётся ДД.ММ.ГГГГ на обоих языках.
